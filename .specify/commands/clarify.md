# Command: /speckit.clarify

## Input
Target feature specification in `specs/NNN-<feature>/spec.md`.

## Execution Workflow
1. **Audit Spec**:
   - Check for vague statements, unstated assumptions, or missing edge cases.
   - Verify that all user stories have concrete acceptance criteria.
2. **Surface Key Questions**:
   - Pose concise, targeted questions to the user regarding UX preferences, technical constraints, or data modeling choices.
3. **Refine `spec.md`**:
   - Incorporate the answers directly into the specification.
